# 🖼️ CodeAlpha Image Gallery

A fully responsive image gallery built with **HTML, CSS, and JavaScript** (no frameworks) as part of the **CodeAlpha Web Development Internship — Task 1**.

## 🔗 Live Demo
[View Live Demo](#) <https://piyushpranto.github.io/CodeAlpha_Image_Gallery/>


## ✨ Features
- **Responsive grid layout** — adapts smoothly from desktop to mobile (3 → 2 → 1 columns)
- **Category filtering** — filter images by Nature, City, or Travel with a single click
- **Lightbox viewer** — click any image to open a full-screen preview
- **Next / Previous navigation** — browse through images inside the lightbox
- **Keyboard controls** — `←` `→` to navigate, `Esc` to close the lightbox
- **Hover animations** — smooth zoom and lift effects on gallery items
- **Mobile-friendly navigation** — collapsible hamburger menu on small screens
- **Accessible** — keyboard-focusable gallery items and ARIA labels for screen readers

## 🛠️ Built With
- **HTML5** — semantic markup
- **CSS3** — Flexbox, CSS Grid, custom properties (variables), media queries
- **Vanilla JavaScript** — DOM manipulation, event handling, no external libraries

## 🚀 Getting Started
1. Clone the repository
   ```bash

   ```
2. Open `index.html` in your browser — no build step or dependencies required.
